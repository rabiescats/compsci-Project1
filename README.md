# compsci-Project1

### Project 1
## siegeDemake

Path: AP

User: Someone who enjoys tactical shooters and wants to recreate that style of gameplay in a singleplayer environment. Less methodical than than games such as ready or not.

Problem: Needing to be online or in multiplayer games in order to find a compelling Tactical shooter experience.

Features:
Destructible maps elements

Fully interactive CPU enemies (and allies?) that should react to the player, signs of his presence, and the changing map and hazards in it.

Alternate loadouts for the player character. A working primary, secondary, and melee slot. Player should have at least one alternative option in the primary and secondary slots.

Question: How do we implement CPU players with behaviors that seem emergent and tactical? How will they respond to the changing map?
